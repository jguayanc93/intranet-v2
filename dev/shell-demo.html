Demo del shell

El navbar, el sidebar y la barra inferior de esta página los inyecta core/cdk-shell.js; no hay nada de eso escrito en el HTML. El backend está simulado, así que funciona sin la API levantada. Estrecha la ventana por debajo de 768 px para ver el sidebar convertirse en barra inferior.

Avisos
